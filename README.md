# 🌾 SHIVSAR EXPORT – Official Website

Welcome to the official repository of **SHIVSAR EXPORT**, a leading agricultural export business from India. Our company is focused on delivering top-grade **Indian onions** and other agricultural produce to markets worldwide.

🔗 **Live Site:** [https://shivsarexport.com](https://shivsarexport.com)

## 📍 About the Project

This project is the official website for **Shivsar Export** — built to present the company’s mission, quality standards, and facilitate customer inquiries through a contact form. The design is responsive, user-friendly, and reflects the brand's identity and professionalism.

## 🚀 Features

- 🌐 Responsive and modern website layout
- 📬 Contact form with backend processing and database storage
- 🔐 Admin panel to view and manage inquiries
- 🧭 Clear navigation and clean UI
- ⚡ Fast load time and optimized for SEO

## 🛠️ Technologies Used

- **HTML5** – Semantic and clean structure  
- **Tailwind CSS** – Utility-first CSS framework for responsive design  
- **JavaScript** – Client-side interactivity  
- **PHP** – Backend logic for handling form submissions and admin features  
- **MySQL** – Storing user messages from the contact form  
- **XAMPP** – Local development server for PHP and MySQL
